厦大统一门户 · 功能演示文档
===============

  用于当众演示（面试 / 答辩 / 给同学看）。全程 6–8 分钟，
  每一步都写清了"点哪里、屏幕会出现什么、这句话要说明什么"，可以照着念。
  文中所有数字都是跑出来的，不是估计；末尾附了现场可复跑的命令。

  收录条目：320 条，来自 39 个板块分组

  分类维度：校区 / 对象 / 用途 / 端 / 形态（5 维）

  首页精选：7 个（教务服务平台、信息门户、本科生选课系统、厦大官网、数字化教学平台、体育教学部、
    图书馆）

  形态分布：网站系统 271 · 小程序 21 · 公众号 12 · 企业微信 4 · 易混淆 10 · App 1 · 云闪付 1

  端分布：电脑端 276 · 手机端 35 · 双端 7 · 线下 2

  角色分布：能直接办事 109 · 机构/说明 211

  校区分布：通用 291 · 漳州 14 · 翔安 11 · 思明 7 · 马来西亚 1

  代码规模：后端 1480 行 · 前端 2245 行 · 样式 1753 行 · 数据流水线 1130 行；零第三方依赖

  交付形态：桌面 exe（绿色版 / 单文件）＋ 手机 PWA ＋ 公网网址，同一份前端

  320 条入口按校区 / 对象 / 用途 / 端 / 形态分好，说一句大白话就能找到该去哪。
  它不抢业务系统的活——它是那把钥匙串，不是锁。"

1. 演示前准备（1 分钟，别省）
====================================================================

  · ① 起桌面版
      命令 / 操作：双击 dist\厦大统一门户-绿色版\厦大统一门户-绿色版.exe
      目的：功能最完整的一版

  · ② 手机版就绪
      命令 / 操作：手机浏览器打开 https://whimsical-melomakarona-c3866a.netlify.app/（桌面版首页
                   底部也写着这个网址，可一键复制），先点一次「📲 装到主屏」
      目的：后面演示手机端时不用等

  · ③ 确认公网是最新版
      命令 / 操作：python tools/deploy_check.py <网址>
      目的：它会逐字节比对线上与本地；出现"传的是旧版本"就重新拖一次 dist-mobile，否则手机端演示
            的是旧界面

  · ④ 数据是干净的
      命令 / 操作：若想演示"首次打开问身份"，先删 dist\data\userdata.json
      目的：让"问一次校区+身份"这一步能演出来

  · ⑤ 关掉多余窗口
      命令 / 操作：关掉浏览器其它标签页
      目的：演示"打开后浏览器窗口会跳到软件前面"时才看得清

  备用：不想动 exe 就用源码 python app.py；只想演示手机端就用公网网址 + 手机投屏。

2. 演示脚本（六段，每段约 1 分钟）
====================================================================

  第 1 段 · 首页不是卡片墙（30 秒）

操作：打开软件，停 3 秒别动。

屏幕表现：欢迎区（校徽 + 数据徽章）→ 10 个常用场景 → 7 个精选入口 → 3 张维度卡 →
底部「浏览全部 320 个入口」。

说明：
  "320 条一次性铺开就是灾难。所以默认落地页是入口的入口：
  常用场景让人一眼看到'查成绩''宿舍报修'这些高频事，精选 7 个是全校最常用的系统，
  下面三张维度卡可以直接按用途 / 端 / 形态钻进去。"

证据：node .devtools/ui_render_test.mjs → 首页可见、列表默认隐藏、精选恰好 7 个。

---

  第 2 段 · 说人话就能找到（1 分钟）★ 核心

操作：在搜索框输入 宿舍水管漏了（不要输"报修"）。

屏幕表现：直接进列表，第一条是 厦大后勤（手机端），后面是 学生宿舍水控使用指南、智慧后勤·网上报
  修。

说明：
  "这是这个软件最值钱的地方。用户不会说'报修'，他会说'宿舍水管漏了'。
  我们做了意图扩展：识别到'漏 / 堵 / 坏 / 故障 / 跳闸 / 停水'这类词，就自动补上'报修、维修'作为
    检索词。
  这里踩过一个坑：早期的报修关键词被宿舍热水类条目继承了，
  结果问'宿舍水管漏了'，第一条弹出'宿舍热水水控小程序'——答非所问。
  后来把热水的关键词从报修词袋里摘出去，现在'厦大后勤'以 27.5 分稳居第一。"

再补两刀（各 10 秒，证明不是运气）：

  输入       第一条
  ---------  --------------------------------
  成绩       体测预约与成绩查询
  报销       财务信息化综合平台
  预约进校   厦门大学访客预约系统（手机端）
  翔安 热水  学生宿舍热水消费系统（翔安校区）

证据：python tools/check_hotwater.py → 7 组口语提问全部命中正确入口，无结果查询数 0。

  第 3 段 · AI 找入口：不要 Key、断网也能用（1 分钟）

操作：点右上角 ✨ AI 找入口 → 输入 宿舍水管漏了找谁 → 发送。

屏幕表现：候选秒出（本地检索先给三个可点入口）→ 随后给出成句回答，
右下角标着当前引擎。

说明：
  "AI 这块我做了一个降级链：有云端 Key 就用云端，没有就纯本地检索——
  入口照样给全，因为打分逻辑本来就在本地。
  想更强的话，界面里可以一键下载一个本机模型（Ollama，免费、断网可用、不需要任何 Key），
  下载带进度条，装完自动切过去。这个软件默认不花一分钱、也不收集任何数据。"

如果现场有网且装过本机模型：点 ⚙ 展示状态行「Ollama 正在运行，已有 N 个模型」。

证据：python tools/check_ask_empties.py → 19 个问题（含乱码与无关提问）里只有「？？？」会回"没找
  到"。

  第 4 段 · 详情抽屉：每条都能溯源（1 分钟）

操作：点第 2 段里那条 厦大后勤 的 ⓘ（详情）。

屏幕表现：抽屉里有——简介 / 分类标签 / 关键词 / 实测状态 / 收录来源 / 同板块其他入口。

说明：
  "目录工具最怕'这信息哪来的、准不准'。所以每条都标了收录自哪一份总集的哪一节，
  并且逐条实测过链接：能开的、打不开的都写在卡片和详情里。"

指着 ⚠ 角标说：
  "我们实测了目录里所有网址：7 条确实打不开（服务器拒绝脚本访问、需要登录或仅限校园网），
  这些没有删掉，而是保留并标注'用浏览器直接打开通常正常'——因为对用户来说它们仍然有用。
  另外 37 条打开后标题和条目名不一致，会提示'可能已改版'。"

证据：data/link_status.json 逐条记录状态码与检测时间；tools/audit_links.py 可复跑。

  第 5 段 · "打不开怎么办"——89 条都有交代（1 分钟）★ 差异化

操作：在搜索框输入 选课，挑一条没有网址的（小程序类），点开详情。

屏幕表现：抽屉里出现一块 「怎么进（这条没有网址）」：分步说明 + 可点的按钮
（复制名称并打开微信 / 只复制名称），末尾一句兜底。

再点一条打不开的（搜 录取查询）：出现 「打不开？这样进」 →
「先登录统一身份认证」（按钮）＋「打开 WebVPN」（按钮）。

说明：
  "320 条里有 89 条没法直接跳转：45 条是小程序/公众号（微信不开放从网页直接跳），
  44 条实测打不开或已改版。光说'自行搜索'等于没说，所以这些条目都会给可照做的步骤，
  能点的下一步做成按钮——比如需要登录的，直接给它统一身份认证和 WebVPN 的入口。"

证据：node .devtools/entry_help_test.mjs → 无网址 / 需登录 / 仅校园网 / 404 / 502 / 已改版
六类逐一验证，60/60 通过；正常能打开的条目不会出现这块（不打扰）。

  第 6 段 · 一个软件，三个端（1 分钟）

操作顺序：桌面版点任意一条 → 说明浏览器打开与窗口置前 → 转向手机（投屏或递过去）。

说明：
  "同一份前端跑在三个地方：
  ① 桌面 exe——绿色版免安装，双击即用；
  ② 手机 PWA——浏览器打开后『添加到主屏幕』，图标点开就是全屏 App，断网也能翻目录；
  ③ 公网网址——发链接就能用，微信里点开也能看。"

演示两个细节：
  1. 点条目 → 系统浏览器打开，并且浏览器窗口会自动跳到软件前面（Windows 默认不让后台进程抢前台，
    这里做了窗口提权）
  2. 手机上左上角「筛选」：抽屉里能按校区 / 身份 / 用途 / 端 / 形态筛；身份只在首次打开时问一次

发给别人 / 自己手机上用：桌面版首页底部有一块「📱 手机上也能用」，直接把网址写在界面上：

    https://whimsical-melomakarona-c3866a.netlify.app/

配一句说明（同一份数据；手机浏览器打开；在菜单里「添加到主屏幕」后图标点开就是全屏、断网也能翻），
右边两个按钮——复制网址（一键复制，直接发到微信或 QQ）、在浏览器打开（调系统浏览器，窗口会提到最
  前）。
这块只在桌面版出现：手机上本来就在用这个网址，公网静态版也没有后端，都不显示。

证据：python tools/check_mobile_url.py --live（后端给出网址、/api/open 放行它、白名单没被放宽）、
node .devtools/mobile_url_test.mjs（桌面显示 / 手机不显示 / 静态版不显示 + 两个按钮）。

证据：python tools/check_browser_focus.py（浏览器置前 6 组）、
node .devtools/side_menu_test.mjs（手机菜单 28/28）、
node .devtools/zoom_lock_test.mjs（手机禁缩放 19/19）。

5. 预判提问与回答
====================================================================

  这跟学校信息门户有什么区别？→ 门户是"登进去办事"的地方；我们是"告诉你该去哪个系统办、以及为什
    么现在进不去"。不抢业务系统的活——成绩、课表、一卡通余额这些我们只给入口，不去爬接口，因为那
    要维护、有隐私和合规风险

  320 条数据哪来的？准不准？→ 两份官方总集（网址总集 + 小程序总集）解析而来，逐条人工核对分类与
    说明；流水线 build_data.py 带质量闸门，废话模板、可疑字串、人名校验都会拦下来

  链接失效了怎么办？→ 已逐条实测：7 条打不开的保留并标注原因，37 条标题不符的标"可能已改版"，详
    情里给复核时间；tools/audit_links.py 可随时复跑

  AI 要花钱吗？隐私呢？→ 默认不花一分钱：没配任何 Key 时走内置本地检索，入口照样给全。不登录、不
    收集、不上传；收藏和历史只存在本机

  为什么不做微信小程序上架？→ 三道门槛都不在技术侧：① 小程序必须 ICP 备案；② 个人主体不能使用
    web-view（官方文档原文），学校主体又要授权；③ 网页内嵌还受业务域名限制。所以先做"公网网址 +
    加主屏"，微信里点开链接一样用

  数据更新怎么发版？→ 网页/手机版重新部署一次，所有人下次打开就是新的；只有桌面 exe 需要重新打包
    分发——这是网页版最省事的地方

  为什么不用框架？→ 这个体量（320 条 + 本地检索）不需要，而且零第三方依赖意味着现场演示不会因为
    装包失败翻车

  手机上装不到主屏怎么说？→ 页面里有自检：会告诉你当前用的什么浏览器、卡在哪一条（不是 https /
    manifest 类型不对 / 缺 192 图标 / Service Worker 没起来），以及微信里为什么装不了

6. 诚实的边界（主动说，别等被追问）
====================================================================

  1. 小程序无法从外部直接唤起——微信没有开放这个能力，只能"复制名称 → 微信搜一搜"。已在界面里写成
    可照做的步骤。
  2. 有 89 条（28%）无法直接跳转：45 条小程序/公众号没有网址，44 条实测打不开或已改版——这 89 条
    全部给了间接方法。
  3. 数据是人工整理的快照，不保证与官网实时同步；详情里标注了收录来源与复核时间。
  4. 手机 PWA 要 https 且浏览器支持；微信内置浏览器装不了（任何网站都一样）。
  5. 本产品是学生作品、非厦门大学官方产品，界面里也这么写着；数据整理自各单位官网公开信息。
  6. AI 只在已收录条目里选，不会编造入口；但它仍可能挑得不够准，建议以官网为准。
