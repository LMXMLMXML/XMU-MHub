# 厦大统一门户 · LOGO 设计说明

> 一枚**不含任何文字**的图形标志：只用形状和颜色说明"把厦大散落的入口收进一个门户"。

## 一、图形语义（每一笔都有出处）

| 图形 | 含义 | 依据 |
|---|---|---|
| **深蓝圆角方底** | 厦门大学 | 校徽主色 `#0d2f6e`（对官方校徽图片做像素量化，该色占 80.5%） |
| **白色"门"（拱门 + 门洞）** | **统一门户**本身：一个入口 | 门洞是负空间挖出来的，所以它是"能走进去的门"，不是一块牌子 |
| **白色燕尾屋脊** | 厦大地标：嘉庚建筑飞檐 | 校徽里的嘉庚楼群轮廓；两端上翘、中间平缓，是嘉庚屋顶的识别特征 |
| **青色波浪（门洞内）** | 临海厦大 + 信息流 | 信息学院强调蓝 `#0c81bd`，与校徽藏青同色系 |
| **绿色开放环** | OpenHarmony | OH 标志的几何开放环与绿 `#4f9e3f → #75c754`（取自 OH 官方标识）；**环底留口**=开放生态，门正好立在开口处 |
| **环上 6 颗圆点** | 散落的网站 / 小程序 / 公众号 | 官网、教务、图书馆、一卡通、报修、场馆……点多而不乱，围绕门户排布 |
| **点与门的关系** | "多路 → 一门" | 点是"来源"，门是"归处"，这就是这个软件在做的事 |

三色只用了三种来源：校徽藏青（#0d2f6e）、信息学院蓝（#0c81bd）、OH 绿（#4f9e3f/#75c754）——
**没有第四种颜色**，因此它在任何界面里都不会显得是"外来图标"。

## 二、为什么这样做（设计取舍）

- **不用校徽本体**：校徽是学校的正式标识，把它塞进一个软件图标里既不合规也不好看；
  改用"嘉庚屋檐 + 门洞 + 海浪"这些**可识别的图形语言**，一看就知道是厦大。
- **不用字母/文字**：不写"XMU""OH""门户"任何字样——小尺寸下文字必糊，
  而且中英混排会让图标变成"标签图"。全部信息交给形状。
- **不用 OH 的字标**：OH 的"OH"是字母组合，直接搬过来会变成"文字"；
  因此只取它的**几何语言**：开放环 + 圆点 + 绿。
- **小尺寸单独出图**：32px / favicon 用简化版（去掉圆点与波浪），
  只保留"绿环 + 白门"这个最小可识别组合，避免缩到 16px 变成一团糊。

## 三、文件清单

| 文件 | 用途 |
|---|---|
| `logo-portal.svg` | 主标志（深蓝底，矢量，任意放大） |
| `logo-portal-light.svg` | 浅色界面用（浅底 + 藏青图形） |
| `logo-portal-mark.svg` | 透明底图形标（不含底色，可叠在任何背景） |
| `logo-portal-mono.svg` | 单色标（白色），用于深色/照片/水印 |
| `logo-512.png` / `-256` / `-128` / `-64` | 位图尺寸阶梯（含圆点与波浪的完整版） |
| `logo-32.png` | 小尺寸简化版（保留最少元素） |
| `logo-512-light.png` | 浅底位图 |
| `logo-256-mark.png` | 透明底位图 |
| `favicon.ico` | 多尺寸图标（16/32/48/64），已挂到 `web/index.html`，也就是**窗口/标签页**图标 |
| `app.ico` | **Windows 应用程序图标**（Explorer / 任务栏 / Alt-Tab），16/24/32/48/64/128/256 七个尺寸，由 `tools/make_logo.py` 手写 ICO 容器生成——小尺寸用简化图形，大尺寸用完整图形；打包时通过 PyInstaller `--icon` 嵌入 exe |
| `logo-preview.png` | 对照图：尺寸阶梯 + 浅底/透明/单色四种形态 |

重新生成（改几何参数或配色后跑一次）：

```bat
python -m pip install --target D:\AI\xmu_hub\.buildtools pillow
set PYTHONPATH=D:\AI\xmu_hub\.buildtools
python tools\make_logo.py
```

一切几何都在 `tools/make_logo.py` 顶部的常量区（环半径、缺口角度、门洞宽高、屋脊上翘量…），
SVG 与 PNG 由同一套常量生成，**不会出现"矢量版和位图版长得不一样"**。

## 四、使用规范

- **最小尺寸**：完整版 ≥ 64px；≤ 48px 请用 `logo-32.png` 这类简化版。
- **留白**：四周留出至少"环宽"（≈ 标志宽度的 5%）的空隙，不要贴边。
- **不要**：拉伸变形、加描边、换第四种颜色、把门洞填成实心、在标志上叠文字。
- **深色界面**用主标志或单色标，**浅色界面**用 light 版或透明标。

## 五、配色取值（与前端设计系统一致）

```
--brand    #0d2f6e   校徽藏青（主）
--brand-mid#1b4494   渐变中间色
--accent   #0c81bd   信息学院蓝（波浪）
--oh-green #4f9e3f   OpenHarmony 绿（环，深）
--oh-green-l #75c754 OpenHarmony 绿（环，亮）
```
